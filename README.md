Design an interactive financial performance dashboard using Excel to analyze business performance for the provinces of Hanoi, Da Nang, Ho Chi Minh City and Total. Simultaneously, provide viewers with a comparison of actual results against the budget.
The dashboard provides a complete overview of:
- Monthly Revenue, Expense and Profit Trends.
- Analyze the actual profit margin against the budgeted profit margin.
- Analyze the expense of each category to identify the category with actual expense overruns.
- Analyze the contribution of each province to the overall performance.
This project focuses on controlling performance indicators by monitoring budgets and actual to manage reports for helping stakeholders evaluate both growth and expense effectiveness for each province/category.
